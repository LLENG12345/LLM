| 文件 | 职责 |
| --- | --- |
| src/ntl/labels.py | 唯一官方标签定义、固定 class_order |

## 实验和配置接口

```powershell
.\.venv\Scripts\python.exe scripts/run_experiment.py --mode smoke --run-id example_smoke
.\.venv\Scripts\python.exe scripts/run_experiment.py --mode formal --run-id example_cv --smoke-run example_smoke
```

run-id 对应目录必须不存在。支持 --data-dir、--config 和 --purpose。旧 run_s04.py 使用相同选项，run_s05.py 保留原全量运行命令。正式五折仍要求先有匹配配置和数据指纹的单折冒烟；不会复用与新代码记录不匹配的旧运行。

默认设置通过 models.baseline_config 组合唯一特征默认值和分类器设置，每次返回深拷贝；make_model 每折创建新实例。配置 JSON 是显式覆盖，例如 `{"branches":["word"]}`、`{"branches":["char"]}` 或 `{"classifier":{"C":0.5}}`；构造和实际 get_params 都写入运行配置。不支持的键/分支明确失败。这里只说明调用能力，本轮没有正式运行这些覆盖配置的官方五折。

Python 直接入口为 run_experiment(run_id, mode, config, data_dir, project_root, smoke_run, purpose)。研究 01 Notebook 调用它做单折/五折，再展示指标并可选全量预测；00 EDA 调用公共数据和分析函数。所有完整研究产物使用独立运行目录，原历史资源不覆盖。
