# Name That LLM 实验评价协议

协议版本：v1，2026-11-19，S07-A。适用模型由唯一 run_id、源码/配置、数据/分折 SHA 与官方 `ntl.labels.class_order` 识别。实现见 `src/ntl/evaluation.py`，真实结果见 [S07-A 报告](../experiments/s07a_protocol_20261119_01/report.md)，来源与未知事项见 [研究核实](S07-A_研究资料核实.md)。

## 1. 三层评价

1. **full_group_cv 为主。** 保留 folds_v1、所有验证 ID、各折 fit 范围及历史评分。以 ID 对齐 2699 条完整 OOF，汇总 18 类 recall 均值为 BA，同时报告 Accuracy、18 类 Macro F1、混淆、逐折表现、资源。标签/id/prompt 不进文本特征；词表、缩放、校准和学习器只在合法训练范围 fit。
2. **sparse_group_cv_k2 为补充候选。** 对固定 OOF 的验证行抽样，训练折、预测和分数一律不变，不做联合分配或批次校正。未抽中验证行仍留在验证侧，不能回填训练。不是社区 Hungarian 方法的复现，也不是新测试集。
3. **folds_v2 预留稳定性复核。** 历史文件不变，本轮不训练/选模。候选和改进假设冻结后才用；若根据 v2 继续迭代，须明确它已成为开发数据，不能仍称独立最终复核。

## 2. 稀疏掩码冻结

资源：`experiments/evaluation_masks/sparse_k2_v1/{masks.csv,metadata.json}`。

- 在首次读取稀疏预测分数前，固定 10 个 seed：`20261119,20262128,20263137,20264146,20265155,20266164,20267173,20268182,20269191,20270200`。不是日历日期校验；为 `20261119+1009*i`，i=0..9。
- 算法 `sha256-rank-per-prompt-k2-v1`：只读 id/prompt_id/fold；按 prompt、id 规范排序。每个候选 ID 以 UTF-8 JSON 紧凑序列 `[algorithm,seed,prompt_id,id]` 算 SHA-256，按摘要二进制升序、ID 打破平局，取至多两个，输出 ID 排序。无放回；不足两个全保留。依靠固定 hash 排名而非随 NumPy 版本变化的 RNG。
- 不用标签、预测或成绩抽样；支持数在抽样之后按 ID 读取标签统计。不会按类别重抽、删除差种子或择优报告。
- 每行保存 seed/id/prompt_id/fold；元数据保存 seed 列表、算法/版本、训练/分折/掩码原文件 SHA、class_order、每组及每折 18 类支持数、冻结时间。补充指纹在 freeze-receipt.json。
- 生成只允许新目录；读取必须检查 raw SHA、元数据与算法重算结果，拒绝缺失/重复/额外 ID、错误 prompt/fold/seed、数据版本变更。行顺序变化不改变掩码。已有资源禁止覆盖；新协议必须新版本并记录理由。
- 本轮 CSV SHA：`c1c28dcfd25f8e22479a73a851bb7ed1b73be7e13d112a0d6498dff2bd6fe19f`；300 行/seed、150 prompt、60 行/折、总计 3000 条掩码记录。Git 属性将该目录 CSV/JSON 固定为 LF。

## 3. 指标与统计解释

每组首先汇总五折抽中 OOF，再算固定官方 18 类 BA。缺任一类则 BA=null、保留 missing_classes，不能自动改为已出现类别的平均；各类 recall 缺支持则 null。Accuracy 正常报告，Macro F1 显式使用全部 18 类并将零分母记 0。**不平均单折缺类 BA**；保存单折支持表说明原因。

全部 10 组都报告 BA/Accuracy/F1、均值、总体标准差 ddof=0、最小/最大、18 类支持及 recall。任一组 BA 未定义时不静默丢弃后计算“十组均值”。所有模型严格用相同 seed/ID 配对比较和排序；不把最佳 seed 当实验成绩。

这些掩码相互重叠，基于同一批固定 OOF；其标准差是条件抽样变化，**不是**重训练方差、标准误或泛化置信区间。若估计差值区间，以 prompt 为单位对模型配对重采样，保留所有组内行，并说明训练折重叠的限制。本轮没有新增 CI；沿用历史 Bootstrap 只作历史诊断。

## 4. 选型与数据泄漏边界

主要决策依据仍是完整 OOF BA、弱类表现、混淆、成本和失败模式；稀疏表补充考察抽样稳定性。微小提升及十组同向不能单独证明泛化。校准/融合/超参用内层训练验证或诚实交叉拟合，不在外层验证上早停、调参再回报同折独立成绩。

S07-A阶段只有三个独立本地模型；B3完成后为四组模型，但仍只有一个用户确认公榜 .311，不能计算有意义的协议—公榜相关性。S04 与 S06-B 等价模型只算一个观察。队友报告与社区结果属于不同分折、代码、数据和后处理，不能直接拼成相关性样本。未来记录预先确定的候选与同版本公榜回执，公开记录所有失败和未提交候选，防止选择性报告及反复选择协议造成偏差。

逐行模型抽样不改变任意一条预测，只减少观测量；不模拟真实隐藏 prompt 频率、类别比例或领域分布，也不能单凭 k=2 更真实的说法取代完整验证。测试没有 prompt_id；禁止在未核实结构时强制按 18 行分组或均匀分配类别。

## 5. 后续模型统一产物

每个正式模型保存唯一 run_id、来源源码与配置、数据及分折 SHA、固定类别顺序、OOF 的 id/prompt_id/fold/真值/预测、18 维分数及明确类型、BA/Accuracy/F1、各类召回/混淆、训练预测耗时与资源、告警/隔离检查/运行状态。margin、softmax、模型概率、校准概率不可混称。外部资源另存准入证据、许可证、公开时间、base/adapter 版本和污染检查。

本轮结果是历史 OOF 的评价资源，**不向 experiments.csv 添加新的模型成绩行**，也不替换默认模型。Windows 原环境即可执行：
